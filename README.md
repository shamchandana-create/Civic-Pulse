# Civic Pulse 🏛️

### Multilingual Policy, Rights & Scheme Explainer

Civic Pulse is an AI-powered multilingual assistant designed to help citizens understand government schemes and scholarship information in simple language.

## Problem Statement

Citizens often find government scheme information difficult to understand due to complex language, scattered information and language barriers.

## Solution

Civic Pulse uses a local AI model to provide simplified explanations of scheme information available in its knowledge base. It supports English and Kannada.

## Features

- English and Kannada language selection
- Government scheme information database
- Keyword-based scheme search
- AI-generated simplified explanations
- Official source links
- Local AI processing using Ollama

## Technologies Used

- Python
- Streamlit
- Ollama
- Llama 3.2 (3B)
- JSON
